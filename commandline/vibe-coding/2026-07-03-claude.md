**How the filter works.** The dashboard now has an **account dropdown** at the top that filters *everything* — all KPI tables, backlog, percentiles, hit rate, and every chart — between "All accounts", each account in your `my_own_accounts`, and an "(unattributed)" view for emails that matched none of your accounts.

**The key design decision I made** (and why): accounts aren't stored in `metadata.csv` — they're derived by reading each `.eml`'s headers against `my_own_accounts` (via the existing `match_own_account`). For the filter itself, I chose to **pre-render one full set of aggregations per account in Python** and have the dropdown swap between them client-side, rather than shipping raw per-email data and recomputing means/medians/percentiles/Sankey in JavaScript. This keeps *all* the calculation logic in Python (no duplicated, drift-prone metric code in JS) and the file stays fully self-contained and offline. The cost is a payload roughly ×(accounts + 1), which is negligible for a handful of accounts.
